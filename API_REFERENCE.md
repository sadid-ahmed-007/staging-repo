# EduAuth Registry — API Reference

> Base URL: `http://localhost:8080/api`
>
> Standard Response Format:
> - Success: `{ "success": true, "message": "...", "data": { } }`
> - Error: `{ "success": false, "message": "...", "errors": { "field": "msg" } }`

---

## Public (No Auth Required)

### GET /api/verify/system-stats
- **Auth:** None
- **Description:** Returns system-wide statistics for the landing page.
- **Request:** None
- **Response:**
  ```json
  {
    "success": true,
    "totalSystemUsers": 42,
    "totalUniversities": 5,
    "totalCertificates": 150
  }
  ```

### POST /api/verify/certificate
- **Auth:** None
- **Description:** Public certificate verification using serial number and date of birth.
- **Request Body:**
  ```json
  {
    "serial": "BSC-26-000001M",
    "date_of_birth": "2000-01-15"
  }
  ```
- **Response (success):**
  ```json
  {
    "success": true,
    "verified": true,
    "message": "Certificate verified successfully",
    "certificate": {
      "serial": "BSC-26-000001M",
      "student_name": "John Doe",
      "student_id": "ENR-001",
      "certificate_level": "Bachelor of Science",
      "program": "Computer Science",
      "major": "Software Engineering",
      "registration_no": "ENR-001",
      "cgpa": 3.75,
      "issue_date": "2026-01-15",
      "completion_date": "2025-12-20",
      "institution": "National University",
      "issued_by": "University",
      "status": "valid",
      "is_public": true
    }
  }
  ```
- **Response (not found):** `404 { "success": false, "verified": false, "message": "Certificate not found..." }`
- **Response (DOB mismatch):** `401 { "success": false, "verified": false, "message": "Date of birth does not match..." }`
- **Response (revoked):** `200 { "success": true, "verified": false, "status": "revoked", ... }`
- **Response (private):** `403 { "success": false, "verified": false, "message": "This certificate is private..." }`
- **Response (invalid checksum):** `400 { "success": false, "verified": false, "message": "Invalid certificate serial number format" }`

### GET /api/verify/link
- **Auth:** None
- **Description:** Verify a certificate via encrypted share link.
- **Request Params:** `s` (serial), `v` (encrypted DOB token)
- **Response:** Same as POST /api/verify/certificate
- **Notes:** The `v` token is an AES-encrypted date of birth generated by the backend.

## Auth

### POST /api/auth/register
- **Auth:** None
- **Description:** Register a new user (student, university, or verifier). Sends OTP email.
- **Request Body (student):**
  ```json
  {
    "email": "student@example.com",
    "password": "password123",
    "confirmPassword": "password123",
    "role": "student",
    "firstName": "John",
    "middleName": "",
    "lastName": "Doe",
    "dateOfBirth": "2000-01-15",
    "gender": "Male",
    "nid": "1234567890",
    "phone": "+8801712345678",
    "address": "123 Main St, Dhaka"
  }
  ```
- **Response:** `201 { "success": true, "message": "Registration successful. Please check your email to verify your account." }`

### POST /api/auth/verify-email
- **Auth:** None
- **Description:** Verify email with OTP code received via email.
- **Request Body:**
  ```json
  { "email": "student@example.com", "code": "123456" }
  ```
- **Response:** `200 { "success": true, "message": "Email verified successfully." }`

### POST /api/auth/resend-verification
- **Auth:** None
- **Description:** Resend the OTP verification code.
- **Request Body:**
  ```json
  { "email": "student@example.com" }
  ```
- **Response:** `200 { "success": true, "message": "Verification code resent." }`

### POST /api/auth/login
- **Auth:** None
- **Description:** Login with email and password. Returns JWT token.
- **Request Body:**
  ```json
  { "email": "admin@eduauth.com", "password": "admin123" }
  ```
- **Response:**
  ```json
  {
    "token": "eyJhbGciOiJIUzI1NiJ9...",
    "user": {
      "id": 1,
      "email": "admin@eduauth.com",
      "role": "admin",
      "isApproved": true,
      "emailVerified": true,
      "profile": null
    }
  }
  ```
- **Notes:** Token is stored in localStorage. Frontend reads `response.data.token` directly.

### POST /api/auth/logout
- **Auth:** Bearer Token (any role)
- **Description:** Logout and blacklist the current JWT token.
- **Request:** Authorization header with Bearer token
- **Response:** `200 { "success": true, "message": "Logged out successfully." }`

### GET /api/auth/me
- **Auth:** Bearer Token (any role)
- **Description:** Get the current authenticated user's profile.
- **Response:**
  ```json
  {
    "success": true,
    "user": {
      "id": 1,
      "email": "admin@eduauth.com",
      "role": "admin",
      "isApproved": true,
      "emailVerified": true,
      "profile": { ... }
    }
  }
  ```

## Student

### GET /api/student/dashboard
- **Auth:** Bearer Token (STUDENT)
- **Description:** Get student dashboard statistics.
- **Response:**
  ```json
  {
    "success": true,
    "data": {
      "totalCertificates": 3,
      "publicCertificates": 2,
      "privateCertificates": 1,
      "pendingAccessRequests": 0,
      "activeAccessGrants": 1,
      "currentEnrollment": {
        "institutionName": "National University",
        "program": "BSc Computer Science",
        "batch": "2022",
        "status": "active",
        "enrollmentDate": "2022-01-15",
        "expectedGraduationDate": "2026-01-15"
      }
    }
  }
  ```

### GET /api/student/certificates
- **Auth:** Bearer Token (STUDENT)
- **Description:** List student's certificates (paginated).
- **Query Params:** `filter` (all/public/private), `page` (default 0), `size` (default 25)
- **Response:**
  ```json
  {
    "success": true,
    "data": [ { "id": 1, "serial": "BSC-26-000001M", "certificateName": "...", ... } ],
    "total": 3,
    "page": 0,
    "pages": 1
  }
  ```

### GET /api/student/certificates/{id}
- **Auth:** Bearer Token (STUDENT)
- **Description:** Get full certificate details including share link.
- **Response:**
  ```json
  {
    "success": true,
    "data": {
      "id": 1,
      "serial": "BSC-26-000001M",
      "certificateLevel": "Bachelor of Science",
      "certificateName": "Computer Science",
      "department": "CSE",
      "major": "Software Engineering",
      "shareLink": "http://localhost:5173/verify?s=BSC-26-000001M&v=...",
      "student": { "id": 1, "firstName": "John", "lastName": "Doe" },
      "institution": { "id": 1, "name": "National University" },
      "enrollment": { "enrollmentNumber": "ENR-001", ... }
    }
  }
  ```
- **Notes:** Certificate must belong to the authenticated student.

### GET /api/student/certificates/{id}/pdf
- **Auth:** Bearer Token (STUDENT)
- **Description:** Download certificate as PDF with QR code.
- **Response:** Binary PDF file with headers:
  - `Content-Type: application/pdf`
  - `Content-Disposition: attachment; filename="BSC-26-000001M.pdf"`
- **Notes:** Frontend must call with `{ responseType: 'blob' }`.

### PATCH /api/student/certificates/{id}/visibility
- **Auth:** Bearer Token (STUDENT)
- **Description:** Toggle certificate public/private visibility.
- **Request Body:**
  ```json
  { "isPubliclyShareable": false }
  ```
- **Response:**
  ```json
  { "success": true, "message": "Certificate is now private", "isPubliclyShareable": false }
  ```

## University

### GET /api/university/dashboard
- **Auth:** Bearer Token (UNIVERSITY)
- **Description:** Get university dashboard statistics.
- **Response:**
  ```json
  {
    "success": true,
    "data": {
      "totalEnrolled": 150,
      "graduatedStudents": 45,
      "certificatesIssued": 40,
      "pendingWithdrawals": 2,
      "thisMonthCertificates": 5
    }
  }
  ```

### GET /api/university/certificates
- **Auth:** Bearer Token (UNIVERSITY)
- **Description:** List certificates issued by this university (paginated).
- **Query Params:** `page`, `size`, `level` (all/BSc/MSc/...), `month` (YYYY-MM), `search`
- **Response:**
  ```json
  {
    "success": true,
    "data": [ { "id": 1, "serial": "...", "studentName": "...", ... } ],
    "total": 40,
    "page": 0,
    "pages": 2
  }
  ```

### GET /api/university/certificates/{id}
- **Auth:** Bearer Token (UNIVERSITY)
- **Description:** Get full certificate details. Must belong to this university.
- **Response:** `{ "success": true, "data": { ... } }`
- **Notes:** Returns 403 if certificate doesn't belong to the authenticated university.

## Verifier

### GET /api/verifier/dashboard
- **Auth:** Bearer Token (VERIFIER)
- **Description:** Get verifier dashboard statistics.
- **Response:**
  ```json
  {
    "success": true,
    "data": {
      "accessibleStudents": 3,
      "pendingRequests": 1,
      "approvedRequests": 5,
      "rejectedRequests": 0,
      "verificationsToday": 2,
      "totalVerifications": 45
    }
  }
  ```

### POST /api/verifier/verify
- **Auth:** Bearer Token (VERIFIER)
- **Description:** Verify a certificate (logged under verifier's account).
- **Request Body:**
  ```json
  { "serial": "BSC-26-000001M", "date_of_birth": "2000-01-15" }
  ```
- **Response:** Same structure as POST /api/verify/certificate

### GET /api/verifier/verifications/stats
- **Auth:** Bearer Token (VERIFIER)
- **Description:** Get verification statistics and recent verifications.
- **Response:**
  ```json
  {
    "success": true,
    "stats": {
      "total_verifications": 45,
      "successful_verifications": 40,
      "failed_verifications": 5,
      "verifications_today": 2
    },
    "recent_verifications": [ { "id": 1, "serial": "...", "result": "success", ... } ]
  }
  ```

### GET /api/verifier/verifications/recent
- **Auth:** Bearer Token (VERIFIER)
- **Description:** Get 10 most recent verifications (for sidebar panel).
- **Response:**
  ```json
  {
    "success": true,
    "verifications": [ { "id": 1, "serial": "...", "serial_masked": "BSC-26-***01M", ... } ]
  }
  ```

### GET /api/verifier/verifications/history
- **Auth:** Bearer Token (VERIFIER)
- **Description:** Paginated, filtered verification history.
- **Query Params:** `page` (1-based), `status` (all/success/failed), `serial`, `from` (YYYY-MM-DD), `to` (YYYY-MM-DD)
- **Response:**
  ```json
  {
    "success": true,
    "data": [ { "id": 1, "serial": "...", "status": "success", "certificate": { ... }, ... } ],
    "total": 45,
    "per_page": 15,
    "current_page": 1,
    "last_page": 3
  }
  ```

### GET /api/verifier/verifications/export
- **Auth:** Bearer Token (VERIFIER)
- **Description:** Export verification history as CSV.
- **Query Params:** `status`, `serial`, `from`, `to`
- **Response:** CSV file download

### GET /api/verifier/accessible-certificates
- **Auth:** Bearer Token (VERIFIER)
- **Description:** List students this verifier has active access to.
- **Response:**
  ```json
  {
    "success": true,
    "data": [ { "studentId": 1, "studentName": "John Doe", "certificateCount": 3, ... } ]
  }
  ```

### GET /api/verifier/accessible-certificates/{studentId}
- **Auth:** Bearer Token (VERIFIER)
- **Description:** List all certificates for a specific student (requires active access grant).
- **Response:**
  ```json
  {
    "success": true,
    "student": { "id": 1, "name": "John Doe", "email": "..." },
    "accessExpires": "2026-09-15T00:00:00",
    "data": [ { "id": 1, "serial": "...", ... } ],
    "total": 3
  }
  ```
- **Notes:** Returns 403 if access grant is expired or revoked.

## Admin

### GET /api/admin/dashboard
- **Auth:** Bearer Token (ADMIN)
- **Description:** Get admin dashboard statistics.
- **Response:**
  ```json
  {
    "success": true,
    "data": {
      "pendingApprovals": 3,
      "totalUsers": 42,
      "totalCertificates": 150,
      "totalUniversities": 5,
      "totalStudents": 30,
      "totalVerifiers": 7
    }
  }
  ```

### GET /api/admin/users
- **Auth:** Bearer Token (ADMIN)
- **Description:** List all users (paginated, filtered).
- **Query Params:** `status` (all/approved/pending/suspended), `role` (all/student/university/verifier), `search`, `page`, `size`
- **Response:** `{ "success": true, "data": { "content": [...], "totalElements": 42, ... } }`

### GET /api/admin/users/{id}
- **Auth:** Bearer Token (ADMIN)
- **Description:** Get detailed user info including profile.
- **Response:** `{ "success": true, "data": { "id": 1, "email": "...", "role": "...", "profile": { ... } } }`

### POST /api/admin/users/{id}/approve
- **Auth:** Bearer Token (ADMIN)
- **Description:** Approve a pending user account. Sends approval email.
- **Response:** `{ "success": true, "message": "User approved successfully" }`

### POST /api/admin/users/{id}/suspend
- **Auth:** Bearer Token (ADMIN)
- **Description:** Suspend a user account.
- **Request Body:**
  ```json
  { "reason": "Violation of terms of service" }
  ```
- **Response:** `{ "success": true, "message": "User suspended successfully" }`

### POST /api/admin/users/{id}/unsuspend
- **Auth:** Bearer Token (ADMIN)
- **Description:** Unsuspend a previously suspended user account.
- **Response:** `{ "success": true, "message": "User unsuspended successfully" }`

### GET /api/admin/certificates
- **Auth:** Bearer Token (ADMIN)
- **Description:** List all certificates (paginated, filtered).
- **Query Params:** `page`, `size`, `status` (all/active/revoked), `institutionId`, `search`
- **Response:**
  ```json
  {
    "success": true,
    "data": [ { "id": 1, "serial": "...", "studentName": "...", "status": "active", ... } ],
    "total": 150,
    "page": 0,
    "pages": 6
  }
  ```

### GET /api/admin/certificates/{id}
- **Auth:** Bearer Token (ADMIN)
- **Description:** Get full certificate details including student, institution, enrollment info.
- **Response:** `{ "success": true, "data": { ... } }`

### POST /api/admin/certificates/{id}/revoke
- **Auth:** Bearer Token (ADMIN)
- **Description:** Revoke an active certificate.
- **Request Body:**
  ```json
  { "reason": "Certificate issued in error — student did not complete requirements" }
  ```
- **Response:**
  ```json
  {
    "success": true,
    "message": "Certificate revoked successfully",
    "data": { "id": 1, "serial": "...", "status": "revoked", "revokedAt": "...", "revocationReason": "..." }
  }
  ```
- **Notes:** Reason must be at least 10 characters.

### POST /api/admin/certificates/{id}/restore
- **Auth:** Bearer Token (ADMIN)
- **Description:** Restore a previously revoked certificate.
- **Request Body (optional):**
  ```json
  { "reason": "Revocation was made in error" }
  ```
- **Response:**
  {
    "success": true,
    "message": "Certificate restored successfully",
    "data": { "id": 1, "serial": "...", "status": "active" }
  }
  ```

## ⚠️ Unimplemented / Missing Endpoints

The following endpoints are currently called by the React frontend but have **not yet been implemented** in the Spring Boot backend. They will currently return a `404 Not Found` response.

### User Profile & Settings
- `GET /api/settings` — Get user settings
- `GET /api/profile` — Get user profile
- `GET /api/profile/activity` — Get user activity log
- `GET /api/profile/change-requests` — Get profile change requests

### Notifications
- `GET /api/notifications` — Get user notifications list
- `GET /api/notifications/unread-count` — Get unread notification count

### Student Actions
- `GET /api/student/withdrawal/requests` — List student withdrawal requests
- `GET /api/student/extension-requests` — List student extension requests
- `GET /api/student/enrollment-applications` — List enrollment applications
- `GET /api/student/program-change-requests` — List program change requests
- `GET /api/student/access-requests` — List certificate access requests
- `GET /api/student/granted-access` — List granted access permissions

### University Actions
- `GET /api/university/withdrawal/pending` — List pending withdrawal requests
- `GET /api/university/extension-requests` — List extension requests
- `GET /api/university/enrollment-applications` — List enrollment applications
- `GET /api/university/enrollments/programs` — List available programs

### Admin Actions
- `GET /api/admin/pending-users` — List pending users awaiting approval
- `GET /api/admin/profile-change-requests` — List profile change requests
